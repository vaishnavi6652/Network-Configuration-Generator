# Python-Based Network Configuration Generator

## Project Description
This project generates Cisco network configuration commands using a Python web interface.

## Features
- VLAN Configuration
- Input Validation
- Automatic Subnet Calculation
- Cisco Configuration Generation
- Download Configuration as a Text File
- Network Testing using Cisco Packet Tracer

## Technologies Used
- Python
- Streamlit
- IP Addressing and Subnetting
- Cisco Packet Tracer
- GitHub
